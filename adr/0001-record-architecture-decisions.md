# ADR-0001: Record architecture decisions

## Status

Accepted

## Context

Identity Platform uses Spec-Driven Development. Significant technical choices must be traceable.

## Decision

We use Architecture Decision Records in `adr/` numbered sequentially. Each ADR has status: Proposed, Accepted, Superseded.

## Consequences

- New contributors read ADRs before changing auth, email, or API versioning
- Superseded ADRs remain for history
